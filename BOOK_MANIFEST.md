# BOOK MANIFEST

Mission

Teach engineering.

Not frameworks.

---

Core Principle

Readers should understand systems deeply enough
to replace any framework.

---

Non-negotiable Rules

Always teach WHY first.

Always build manually first.

Always compare alternatives.

Always explain trade-offs.

Always update the same project.

Always write production-quality code.

Always discuss debugging.

Always discuss security.

Always discuss performance.

Always discuss evaluation.

---

Success Metric

A reader who completes this book should be capable of designing and implementing a production AI agent platform from first principles, evaluating architectural trade-offs, and adapting to new frameworks without relying on tutorials.
